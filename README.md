# Open Art Explorer

An open-source Android app for exploring artworks from public museum collections.

> **Status: pre-alpha, repository setup only.** There is no application code, build or release yet. Everything below describes goals, not working features.

## Goals (planned)

- A free, native Android app for browsing and learning about artworks.
- First data provider: The Metropolitan Museum of Art Collection API, behind an adapter so more providers can be added later.
- Show an artwork image only when its source states clearly that the image may be shown. Otherwise show the artwork's information and link to the source.
- Run well on older and low-end phones (minimum Android 6.0, API 23) and be accessible.
- No ads, no user accounts and no analytics or tracking in the first version.
- Favorites and saved content stay on the device.
